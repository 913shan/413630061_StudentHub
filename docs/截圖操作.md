# Postman 作業截圖

1. 安裝並開啟 Docker Desktop，完成首次啟動畫面，等待 Engine running。
2. 在專案資料夾雙擊「啟動作業.command」，看到 API 已就緒後，在 Postman 按 Import，選 postman/413630061_StudentHub.postman_collection.json。
3. 開啟「查詢全部學生」，按 Send。保留 GET、http://localhost:8890/api/v1/user/findAll、200 OK 及 JSON body 在畫面中，按 Shift+Command+4 擷取視窗區域，存為 screenshots/findAll/413630061.png。
4. 開啟「新增測試學生（只送一次）」，選 Body → raw → JSON，按 Send。首次新增應回傳 code:200、sid:"51"、_id 和 __v。保留網址、請求 JSON、200 OK 及回應內容，截圖存為 screenshots/insertOne/413630061.png。
5. 若回傳「座號已存在」，先查詢確認是否已有 tkuxx9999；請換一組沒使用過的四碼座號再新增，不要刪除資料庫。

兩張圖需來自自己的 Postman 實際成功畫面。目前專案的 docs/*.json 是先前本機 MongoDB 實測紀錄，不是 Docker 或 Postman 截圖。
